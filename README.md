# Mitrilo CV / Minimalist CV Builder

Editor de currículums: importá PDF/DOCX, editá secciones libres, toggle ES/EN, plantillas Minimal o Classic, exportá a PDF.

## Correr en local

```bash
npm install
npm run dev
```

## Features

- Import PDF / DOCX → campos editables
- Secciones libres (texto, entries, tags) con drag & drop
- Colores por título / subtítulo
- Foto + modo ATS (oculta imágenes)
- Toggle ES / EN (versiones independientes)
- Layouts: **Minimal B/N** y **Classic** (nombre + raya)
- Export PDF vía impresión del browser
